## Репозиторий к ВКР "ИССЛЕДОВАНИЕ СТРУКТУРНОЙ ЦЕЛОСТНОСТИ ПРОСТРАНСТВЕННЫХ СЕТЕВЫХ МОДЕЛЕЙ МЕТОДАМИ ПЕРКОЛЯЦИИ"

Данный репозиторий содержит программный комплекс для моделирования и сравнительного анализа структурной целостности пространственно-вложенных сетей (моделей коннектома) методами $k$-ядерной и $k$-кликовой перколяции. 
Код разработан в рамках выпускной квалификационной работы (ВКР) бакалавра.

## Описание проекта

Комплекс предназначен для оценки топологической уязвимости сложных сетей при таргетированных атаках (последовательном удалении узлов-хабов) и позволяет:
1. Генерировать синтетические 3D-графы с контролем плотности ($\langle k \rangle$) и пространственного штрафа ($\alpha$).
2. Проводить топологическую декомпозицию графов с выделением гигантских связных компонент $k$-ядра и $k$-клик.
3. Парсить и фильтровать эмпирические данные (в частности, коннектом *Drosophila larva*).
4. Оценивать потерю вычислительной способности графа путем интеграции его структуры в архитектуру резервуарных вычислений (Echo State Network, ESN) на классической задаче удержания временной памяти `Parity-N`.

## Требования и установка

Алгоритмы поиска $k$-клик относятся к классу NP-полных задач, поэтому выполнение скриптов на плотных графах требует значительных вычислительных ресурсов. Рекомендуется запуск в облачных средах (Google Colab).

**Библиотеки:**
* `python 3.8+`
* `numpy` (векторизация матричных вычислений ESN)
* `networkx` (топологическая декомпозиция графов)
* `scipy`, `scikit-learn` (статистическая обработка и Ridge-регрессия)
* `matplotlib` (визуализация графиков деградации)
* `pandas` (парсинг исходных датасетов)

Установка зависимостей:

pip install numpy networkx scipy scikit-learn matplotlib pandas
